# A Thousand Miles, One Friendship

A Chinese-inspired interactive birthday gift for Zai Zai, with messages in English
and Chinese.

## Add your photos

Put personal images in [`public/images`](./public/images) using these filenames:

- `zai-1.jpg`, `zai-2.jpg`, and `zai-3.jpg` for the garden frames
- `my-rose.jpg` for the rose chapter

JPG, PNG, and WebP are supported. Compressed images around 1200 pixels on the
longest edge help the page load quickly. See [`public/images/README.txt`](./public/images/README.txt)
for details.

## Run locally

Requirements: Bun or Node.js.

```sh
bun install
bun run dev
```

Run `bun run build` to create a production build and `bun run preview` to preview it.
