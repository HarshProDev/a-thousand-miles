Optional local audio files for Howler.js playback:

- background.mp3  (Gentle Chinese guzheng / flute / ambient instrumental loop)
- envelope.mp3    (Subtle paper/envelope opening sound)
- chime.mp3       (Soft chime for the rose reveal)
- celebration.mp3 (Gentle celebratory chime for the birthday finale)

If any MP3 file is absent, the app seamlessly uses its built-in Web Audio API pentatonic guzheng synthesizer with zero external network requests.
